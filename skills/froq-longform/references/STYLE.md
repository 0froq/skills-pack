# froQ 写作风格指南（按时间线修订版）

> ## ⚠️ 首要规则（每次动笔前必读）
> 1. **模仿 froQ 时，默认使用最新阶段（P4，2025-10 起，尤其 2026 年的帖子）。** 旧阶段的梗和腔调不是「他的本色」，只是他过去的样子。
> 2. **他的风格一直在变。每写一篇 essay 之前，先重新拉取 `0froq/0froq.github.io` 的 `docs/`，按 `created` 排序，读最新的 3–5 篇亲笔文章**，对照本指南；若最新文章与本指南冲突，以最新文章为准，并更新本文件。
> 3. 下文第 6 节「旧风格」里的词句，**默认不用**。只有在明确要模仿某个旧时期、或 froQ 本人要求时才用。

> 依据：GitHub 仓库 `0froq/0froq.github.io` 中 `docs/` 下全部 markdown，共 64 篇（Essay 20 / Journal 28 / Cabinet 16），2026-10-22 重新读取并按 `created` 排序（64 篇均有 `created`，无需回退 git 历史）。最新一篇亲笔文章：`透明溞不是老鼠`（2026-08-04）。
> **低权重 / 排除**（不是他亲手写的文字）：`260531 夜记 · 先让东西存在`、`260531 日志 · 东山站实验协助…`、`260612 日志 · 论文受挫…`、`260627 日志 · 实验周记`（标注「由 AI 根据我的口述生成」）；`讲英语：…`（2026-04-10，英文原文的中文译本，`translated: true`）。`Speaking English`（2026-03-18）是他口述进手机、App 改语法的英文稿，只作英文参考，权重低。下文所有「最后出现」日期都**不计这些篇**。

## 2. 格式（跨阶段稳定，至今仍在用）

- frontmatter：`title` / `created`（`YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm`）/ `status`（`form` 定稿 / `probe` / `draft`）/ `last_modified`，可选 `kind`、`lang`。——最后见 2026-08-04。
- 骨架：**一句导语 → `---` → 一行小写英文 hashtag → 正文**。——最后见 2026-08-04（`#life #consciousness`）。
  - 导语新趋势：除「如题。」（最后 2026-03-31）「讲讲。」（2026-02-20）「醒了。」（2025-10-13）这种极短式，**2026 年起导语常是一句完整的概括或论断**：「正常一天。」「降雨导致实验盐度故障，在咖啡厅度过下午。」（2026-06-20）「透明溞不是老鼠。可它第一次被我们看见时，确实先是老鼠。」（2026-08-04）。
- 硬换行：源码里在逗号处断行。——仍在用（2026-08-04），但 P4b 长文的行更长，一行常是一整个分句群。
- 直角引号「」框概念/别人的话；中英、数字与单位之间加空格（「2 个 mod」「double shot」）。——最后见 2026-08-04。
- 括号插话：仍有，但从吐槽变成**补充说明**（「（从我个人情况来说，……）」2026-02-20；「（课上时间不足）」2026-03-31）。`透明溞` 全文无括号插话。
- 脚注补注（`[^1]: 注意，已经更名为 LiG。`）——最后 2025-11-30。
- 加粗：**P4 基本不用**（P4 仅 260331 日志里一处 `**第 2 期计划变更**：`）。长文零加粗。
- emoji：全站几乎没有，任何阶段都不用。

### 各栏目（当前做法）
- **Essay（P4）**：两种。①近况/元写作（`并未真正回归`，2025-11-30）：`##` 小标题可以皮（`## ！`、`## 去哪了？`、`## 回哪去？`），含 `## P.S.`、`## 总而言之`；②长篇叙事随笔（`透明溞`，2026-08-04）：**无小标题、无加粗、按日期推进**（「七月十三日早上八点半」「十四日上午采样」「十八日上午，我们返回南京」），首尾原句呼应。月度/不定期 essay 默认往②靠，需要分段时再借①的小标题。
- **夜记（P4）**：`YYMMDD 夜记 · 小标题`，一两个 `##`，可以是纯技术思考（`260220` 讲键盘方案，用「第一个问题」「第二个问题」「此外」组织），不再以「晚安」收尾。
- **日志（P4）**：`YYMMDD 日志[ · 小标题]`。两种：清单式（`## 今天做的` / `## 明天要做的` / `## 今天没做的`，最后 2026-03-31）；**Timelines 式（2026-06 新出现，最新）**：`## Timelines` 下每条一个完整的流水句，有时间点（「12:00-15:30 混合对照桶和实验桶」「十点，自由。」），平铺直叙，几乎不评论。
- **Cabinet**：摘抄格式不变；新增 evergreen 合集（`如此荒诞`，导语一句定义：「荒谬不是世界的属性，而是人与世界对立产生的张力。」2026-02-18）。

## 3. 当前风格（P4，首要模仿目标）

每条后括号内为**最后出现日期**（不计 AI/译文篇）。

**句子与节奏**
- 2026 年的主调：**长而平静的陈述句**，逗号连缀多个分句，节奏匀，不靠感叹号推情绪（2026-08-04）。
- 仍保留**独立成句的短句**做停顿，但它们是事实而非梗：「热没有。」「船继续晃，船回站。」「合照里没有我。」「我接受这个事实。」（2026-08-04）
- **先肯定再拆解**的论证：「说『我参加了』太宽，说『我没有参加』又太轻易。」「若……都不算，……；若这些都算，……。」（2026-08-04）
- 层层递进的链：「数字之后是表格，表格之后是图，图之后是汇报，汇报之后是结果。」（2026-08-04）
- 排比三连仍在：「不过确实在做一些事情，不过确实和『没有动笔』无关，不过确实可堪一讲。」（2025-11-30）

**高频词（当前）**
- 大概（2026-08-04，高频，「我大概每天喝五六杯咖啡」）、严格来说（2026-08-04）、或许（2026-08-04）、未必（2026-08-04）、似乎（2026-08-04）、事实如此（2026-08-04）、严格意义上（2026-08-04）、其实（2026-08-04）、讲讲（2026-08-04）、好像（2026-06-21）、玩意（2026-06-19，「很久没喝过这个玩意了」）、如题（2026-03-31）、我的观点是 / 就我个人而言 / 例子（2026-02-20）、某种意义上（2025-11-30）、总而言之（2025-11-30，作小标题）、可堪一试/可堪一讲（2025-11-30）、栗子（=例子，2025-11-30）、折腾 / 手搓（2025-11-30）、挖坑（亲笔最后 2025-11-30 前后，慎用）。
- 「人」作泛指主语做哲思：「人可以在有人的地方独处」「人总以为自己害怕的是前进，其实真正让人不适的是停下来」（2026-08-04）。这是 P4b 最显著的新特征。

**语气**
- 克制、观察者姿态，**不下结论**：「我没有给这件事下结论。」「这也未必对。」「或者人根本不需要证明。」（2026-08-04）
- 情绪藏进具体物件和重复（空床、上铺空调、冰咖啡、没上的大巴、不在的合照），不点破（2026-08-04）。
- 自嘲仍有，但更淡、更自省：「我花了一整晚修改圆角、字体、配色、行宽和标注。它们大概都是无关紧要的事情……但我还是改了一整晚。」（2026-08-04）；「或者其实我只是在合理化我自己『永远无法满足』的心态罢了。Never mind.」（2025-11-30）
- 日志里是纯平叙：「所以两点我直接下班，回房间。」「咖啡居然偶遇 Suh。」（2026-06-19/21）

**技术内容**：讲成工程推理——问题 → 方案 → side effect → 「不过就我个人而言可以接受」（2026-02-20）；技术词直接英文不解释（home row mods、side effect、CI/CD、Yak Shaving、distro、double shot、Spearman）（最后 2026-08-04）。

**中英混用**：英文名词照用、句中零星英文（「sort of」2025-10-29；「Never mind.」2025-11-30）；整句法文/大写英文点缀属旧习惯（见第 6 节）。

**他从不做的事（全阶段一致）**：不鸡汤、不升华、不客套感谢、不用 emoji、不「首先其次最后」八股地组织情绪（技术论证时偶用，最后 2025-11-30）、不煽情写痛苦。

## 5. 如何写得像现在的 froQ（清单）

- [ ] **动笔前先读最新 3–5 篇亲笔文章**，确认风格没有再变。
- [ ] 套骨架：frontmatter → 导语（一句完整概括/论断，或「如题。」「讲讲。」）→ `---` → 小写 hashtag → 正文。
- [ ] 长篇：按时间推进（日期、钟点），无加粗，小标题能省则省；首尾用同一句呼应。
- [ ] 以具体事实开口（地点、时间、物件、软件名、数字），再顺势转到用「人」泛指的一两句思考。
- [ ] 思考用「若……，……；若……，……」「说……太宽，说……又太轻易」「这也未必对」，留在开放处，不下结论。
- [ ] 词汇：大概 / 严格来说 / 或许 / 未必 / 似乎 / 其实 / 玩意；技术词英文原样。
- [ ] 至多一处轻自嘲（花一整晚改无关紧要的东西这种），不用网络梗。
- [ ] 结尾：回扣开头的物件或原句，平静收住。

**常见坑**
- 用第 6 节的旧梗（好家伙、属于是、一批、我趣……）——会立刻像 2021–2022 年的他，而不是现在的他。
- 大量加粗、感叹号叠用、括号里密集吐槽（P1/P2 习惯）。
- 在长文里塞梗，或用 P3 那种「何尝不是 / 抑或 / 亦然」的文绉绉虚词堆砌（P4b 的书面感来自句法与精确，而非古雅虚词）。
- 升华、鸡汤、客套、emoji、弯引号「“”」。
- 把 Timelines 日志写成散文，或在日志里加评论。
