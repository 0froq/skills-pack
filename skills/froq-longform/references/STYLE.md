# froQ 写作风格指南

> 用 froQ 的声音写中文 essay / 随笔 / 夜记 / 日志时的当前规范。
> 这不是风格考古——只写"现在怎么写"。历史分期见 git 历史。
> **动笔前必做**：拉 `0froq/0froq.github.io` 的 `docs/` 按 `created` 排序，读最新 3–5 篇亲笔文章；若最新文章与本文件冲突，以最新文章为准，并顺手更新本文件。
> 排除低权重样本：标注「由 AI 根据口述生成」的篇、明确 `translated: true` 的译文、口述稿。

## 格式

- frontmatter：`title` / `created`（`YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm`）/ `status`（`form` 定稿 / `probe` / `draft`）/ `last_modified`，可选 `kind`、`lang`。
- 骨架：**一句导语 → `---` → 一行小写英文 hashtag → 正文**。
  - 导语极短（「如题。」「讲讲。」「醒了。」）或一句完整的概括/论断（「正常一天。」）。
- 硬换行：源码在逗号处断行；长文里一行可以是一整个分句群。
- 直角引号「」框概念或别人的话；中英、数字与单位之间加空格（「2 个 mod」「double shot」）。
- 括号插话只做补充说明，不做吐槽。
- 脚注补注用 `[^1]:`。
- 基本不加粗；emoji 为零。

## 栏目

- **长篇叙事 essay**（默认形态）：无小标题、无加粗，按日期或时间推进（「七月十三日早上八点半」「十四日上午采样」），首尾可用同一句呼应。
- **近况/元写作 essay**：`##` 小标题可以皮（`## ！`、`## 去哪了？`），允许 `## P.S.`、`## 总而言之`。
- **夜记**：`YYMMDD 夜记 · 小标题`，一两个 `##`，可以是纯技术思考，不再以「晚安。」收尾。
- **日志**：`YYMMDD 日志[ · 小标题]`。两种：清单式（`## 今天做的` / `## 明天要做的`）或 **Timelines 式**（`## Timelines` 下每条一个完整流水句，有时间点，平铺直叙几乎不评论）。
- **Cabinet**：摘抄格式不变；evergreen 合集的导语是一句定义。

## 现在的声音

**句子与节奏**
- 长而平静的陈述句，逗号连缀多个分句，节奏匀，不靠感叹号推情绪。
- 独立成句的短句做停顿，内容是事实不是梗：「热没有。」「合照里没有我。」「我接受这个事实。」
- 论证用「先肯定再拆解」：「说『我参加了』太宽，说『我没有参加』又太轻易。」
- 允许层层递进的链：「数字之后是表格，表格之后是图，图之后是汇报，汇报之后是结果。」
- 排比三连偶尔用。

**词汇**
- 高频：大概 / 严格来说 / 或许 / 未必 / 似乎 / 其实 / 玩意 / 某种意义上 / 总而言之 / 可堪一试·可堪一讲 / 折腾 / 手搓 / 挖坑（慎用，已在退出）。
- 「人」作泛指主语做哲思，是当前最显著的特征：「人可以在有人的地方独处」。
- 英文名词照用（home row mods、side effect、CI/CD、Yak Shaving、distro、double shot），句中零星英文可以；整句外文点缀是旧习惯。
- 技术内容讲成工程推理：问题 → 方案 → side effect → 「不过就我个人而言可以接受」。

**语气**
- 克制、观察者姿态，**不下结论**：「我没有给这件事下结论。」「这也未必对。」
- 情绪藏进具体物件和重复（空床、上铺空调、冰咖啡、没上的大巴、不在的合照），不点破。
- 自嘲淡而自省：花一整晚改无关紧要的东西这种；不用网络梗。
- 日志纯平叙，不评论。

**从不做**：鸡汤、升华、客套感谢、emoji、「首先其次最后」八股组织情绪、煽情写痛苦。

## 常见坑

- 网络梗和旧口头禅（好家伙、属于是、一批、我趣、别杠、问题不大、鼓捣、有生之年、你说得对但、6666、一坨、「呃可能是」）——会立刻像过去的他，不是现在的他。
- 大段加粗、感叹号叠用、括号密集吐槽。
- 古雅虚词堆砌（何尝不是 / 抑或 / 亦然）——当前的书面感来自句法与精确，不是虚词。
- 弯引号「“”」；「有人说 / 有人称」。
- 把 Timelines 日志写成散文，或在日志里加评论。
- 升华式收尾。结尾回扣开头的物件或原句，平静收住。
