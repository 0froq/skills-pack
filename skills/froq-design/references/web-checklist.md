# Web UI checklist pointers

Review checklists are not vendored into this skill. Use the installed
vendor skills directly:

- `web-design-guidelines` (Vercel's Web Interface Guidelines): UI
  compliance, accessibility, UX checklist.
- `design-taste-frontend`: anti-slop frontend rules for landing pages,
  portfolios, and redesigns.

The invariants and three dials in this skill's body are froQ's own taste.
The two vendor skills are the "how to check" execution checklists.
